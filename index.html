About me

I have always been fascinated by how computers work and the code that drives them, and these days that has taken me right down to the hardware. I work in embedded systems, writing C for microcontrollers running real-time operating systems (RTOS) in the field of telematics and tracking.

It would seem that I have a special affinity for low-level programming. Outside of work I still have a keen interest in game development, especially how game engines work under the hood, and I enjoy building my own hardware projects.

With a passion for programming languages such as C, C++, C#, Python and JavaScript, I'm always up for a good problem to solve.
